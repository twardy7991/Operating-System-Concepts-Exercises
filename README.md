# Operating-System-Concepts-Exercises
Repository contains solutions for chosen tasks/programming projects presented in Operating System Concepts book.

- Chapter 3: Processes
  - 3.18 - Simple script for creating a zombie process
  - 3.19 - Simple script that takes a command and calculates time needed for its execution
  - 3.20 - Simple Simulation of PID manager
  - 3.21 - Calculate collatz conjecture with child process
  - 3.25 - Echo server and client using C sockets
- Chapter 4: Threads and Concurrency
  - 4.22 - Script that calculates statistical values for list of numbers using single thread
  - 4.24 - Multithreaded pi estimator
  - 4.26 - Date server, that can serve multiple clients and answer with today's date
  - 4.28 - Modification of PID manger from chapter 3, introduces threads that requests PIDs
- Chapter 5: CPU Scheduling
  - Programming Project - Scheduling Algorithms:
      Simulation of scheduling algorithms - FCFS, SJF, Priority scheduling, RR, Priority RR
- Chapter 7: Synchronization Examples
  - 7.14 - Further modification of PID manager, adding mutex locks to ensure protection from race conditions
  - Modification of 4.22, now includes using several threads
  - Programming Projects - The Dining-Philosophers Problem:
    Solutions for dining philosophers problem including:
     - example of bad solution that can result in a deadlock
     - monitor solution
     - semaphore solutions:
         - assymetric solution
         - max4/n-1 solution
         - mutex solution
- Chapter 10: Vritual Memory
  - Programming Project - Designing a Virtual Memory Manager
    Simulation of Memory Managerm, including page table, TLB and physical memory
